# Пример: проверьте сами

Здесь лежит настоящий журнал, запечатанный **настоящим** штампом времени
[freetsa.org](https://freetsa.org) 30 июля 2026 года. Ничего не нарисовано и не
подготовлено специально: те же файлы прогоняются в тестах проекта.

## Две команды

```bash
pip install ./python
aihash verify ./demo/journal
```

Теперь **поменяйте один символ** — откройте
`demo/journal/streams/voice-eu-3/segments/2026-07-29.jsonl`, найдите
`возврат придёт в течение 3 дней` и исправьте `3` на `5`. Запустите ту же
команду ещё раз:

```
НЕ СХОДИТСЯ

  поток voice-eu-3 seq=3: звено не совпадает с записанным
```

Код возврата `1`. Верните символ на место — снова `Запечатано суток: 1`.

## Что здесь есть

| Файл | Что это |
|---|---|
| `journal/` | журнал из 10 записей, штамп RFC 3161 лежит в `anchors/` |
| `episode.seal` | пакет доказательства на **одну** запись из десяти — то, что отдают оппоненту вместо всего журнала |
| `verify.html` | верификатор одним файлом: откройте двойным щелчком, перетащите `.seal` мышью |
| `freetsa-cacert.pem` | корневой сертификат службы. Для проверки **не нужен** — он уже вшит в верификатор; лежит здесь для независимой сверки |
| `aihash.gif` | гифка из README, собранная из настоящего вывода команд |

## Три способа проверить, все офлайн

```bash
aihash verify ./demo/episode.seal              # SDK: сверяет и подпись службы
./verifier/dist/aihash-verify ./demo/journal   # статический бинарь, без зависимостей
open demo/verify.html                          # браузер, перетащите episode.seal
```

Бинарь и страница не разбирают CMS, поэтому про подпись честно говорят «пломба
стоит, но здесь не подтверждена» — и это **не** «пломбы нет». Разницу между
этими двумя ответами продукт считает принципиальной.

## Проверка без нашего кода вообще

Штамп — обычный ответ RFC 3161, его читает `openssl`:

```bash
openssl ts -verify \
  -digest $(python3 -c "import json;print(json.load(open('demo/journal/days/2026-07-29.day.json'))['day_checkpoint'])") \
  -in demo/journal/anchors/2026-07-29.rfc3161.tsr \
  -CAfile demo/freetsa-cacert.pem
```

```
Verification: OK
```

Подставьте суточную отметку из подделанного журнала — получите
`message imprint mismatch`. Ровно это и означает, что пломба несущая: её ставила
третья сторона, и подделать её мы не можем.
